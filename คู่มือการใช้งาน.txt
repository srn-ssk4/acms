	โปรแกรมระบบแข่งขันศิลปหัตถกรรมนักเรียนกลุ่มโรงเรียนศรีรัตนะ สพป.ศรีสะเกษ เขต 4 (รุ่น 2569.07.01) เป็นการสร้างสรรค์โปรแกรม Webpage โดยใช้ Google Gemini ช่วย วิเคราะห์ ตรวจสอบ แก้ปัญหาเชิงระบบ และสร้างโค้ดต้นแบบ โดยใช้การบันทึกข้อมูลต่างๆ ลง Google Sheet และรันเว็ปด้วย GitHub การสร้างสรรค์โปรแกรมในครั้งนี้ใช้การทำงานของระบบแบบพื้นฐานที่รองรับผู้ใช้งานได้จำกัน เนื่องจากกลุ่มโรงเรียนศรีรัตนะมี 26 โรงเรียน และจำนวนผู้เข้าแข่งขันไม่ได้มาก Google Sheet จึงรองรับการทำงานต่างๆ ได้หลาย User พร้อมกัน
	รังสรรค์งานโดย นายทนงศักดิ์  โพธิ์พัฒน์ ผอ.รร.บ้านตาแบน อนาคตเราจะพัฒนาโปรแกรมไปสู่ OOP โดยใช้ฐานข้อมูล MySQL และการเข้ารหัสแบบ SHA-256 Hash ให้สามารถนำขึ้น Host/Domain/Website ได้อย่างปลอดภัย

A: การใช้งานเบื้องต้น
	1. เมื่อ Login เข้าสู่ระบบด้วย User ที่กำหนดให้ ท่านสามารถทำการเปลี่ยนแปลง Password ได้ตามความต้องการ
	2. เมื่อเข้าสู่หน้า "แดชบอร์ด" สามารถเลือก "ธีมทางการ" ที่กำหนดไว้หรือ "ปรับธีม" ได้อิสระตามความต้องการ กดปุ่ม "บันทึกธีม" ระบบจะบันทึกค่าไว้ที่ "ธีมกำหนดเอง" และเมื่่อเข้าสู่ระบบในครั้งถัดไปให้กดเลือก "ธีมกำหนดเอง"
	3. สิทธิ์สำหรับ User ทั่วไป(ผู้ใช้งาน)
		3.1 ดูได้ทุกเมนู
		3.2 สามารถลงทะเบียนนักเรียนได้ แต่ไม่สามารถแก้ไข หรือลบข้อมูลได้ ต้องส่งเรื่องให้ Admin ดำเนินการ
		3.3 สามารถสมัคร "กรรมการจตัดสิน" เมื่อกดปุ่ม "สมัครกรรมการ" โปรแกรมจึงจะนำข้อมูลเข้าระบบ (หากส่งแล้วจะไม่สามารถแก้ไขได้ ต้องส่งเรื่องให้ Admin ดำเนินการเท่านั้น)
		3.4 รายงาน สามาระดูรายงานได้จากปุ่ม "รายงาน" โดยให้รายได้ตาม "รายการแข่งขัน" ,"รายโรงเรียน","ตัวแทนกลุ่ม(คะแนนสูงสุด)"
หมายเหตุ  การกดฟังก์ชั่น Ctrl+F5 ก่อนเริ่มบันทึกข้อมูล ในเครื่องที่เคยใช้ระบบมาก่อน จะช่วยให้ใช้โปรแกรมแบบราบรื่น 

B: การใช้งานบน Smart Phone
	1. เมื่่่อใช้งานบน  Smart Phone เมนูแถบข้างซ้ายจะหายไป ต้องกดปุ่ม "เมนูระบบ" เมนูซ้ายจึงจะปรากฏให้เห็น
	2. การใช้งานบน Smart Phone ควรวางแนวนอน เพื่อความสบายตาในการมอง
	3. การใช้งานปฏิบัติตามขั้นตอน "การใช้งานเบื้องต้น" ทุกข้อ

C: เริ่มต้นกระบวนงาน
	โปรแกรมระบบแข่งขันศิลปหัตถกรรมนักเรียนกลุ่มโรงเรียนศรีรัตนะ สพป.ศรีสะเกษ เขต 4 เป็นโปรแกรมระบบบริหารจัดการแข่งขันทักษะทางวิชาการนักเรียน โดย เริ่มต้นสำหรับ Admin ดังนี้
	1. จัดการโรงเรียน  ไม่อนุญาตให้แก้ไข สามารถแก้ไขได้เฉพาะ Admin(Supervisor) เท่านั้น
	2. จัดการสนามแข่งขัน   การส่งข้อมูลแต่ละรายการกลับมาประมาณ 5-10 วินาที หรือ กดฟังก์ชั่น Ctrl+F5 เพื่อนำค่าปัจจุบันกลับคืนมาในหน้าจอ	
	3. รายการแข่งขัน  การส่งข้อมูลแต่ละรายการกลับมาประมาณ 5-10 วินาที หรือ กดฟังก์ชั่น Ctrl+F5 เพื่อนำค่าปัจจุบันกลับคืนมาในหน้าจอ
ส่วน User สามารถดำเนินการ
	4. ลงทะเบียนนักเรียน  กดบุ่ม "ส่งลงทะเบียน" เพื่อบันทึกข้อมูลเข้าระบบ
	5. กรรมการตัดสิน "สมัครกรรมการ" เพื่อบันทึกข้อมูลเข้าระบบ
การทำงานของ Admin ขั้นต่อไป
	6. ตรวจเอกสาร เมื่อทำการรับรอง/แก้ไขแล้ว ให้กดปุ่ม "สำรองข้อมูลระบบ(Google Sheet)" เพื่อบันทึกข้อมูลเข้าระบบ หรือ กดฟังก์ชั่น Ctrl+F5 เพื่อนำค่าปัจจุบันกลับคืนมาในหน้าจอ
	7. บันทึกผลการแข่งขัน เมื่อบันทึกคะแนนผลการแข่งขันเสร็จแล้ว อาจจะใช้เวลาในการส่งข้อมูลแต่ละรายการกลับมาประมาณ 5-10 วินาที หรือ กดฟังก์ชั่น Ctrl+F5 เพื่อนำค่าปัจจุบันกลับคืนมาในหน้าจอ

หมายเหตุ   เมนูรายการ  แดชบอร์ด และ ตารางอันดับ จะแสดงข้อมูลแบบเรียลไทม์ สามารถดูได้ทุกคน  และเมนู "รายงาน" กดปุ่ม "รายงาน" สามารถดูได้ทุกคน เช่นกัน มีรายการให้เลือกหลายประเภท เช่น "รายการแข่งขัน", "รายโรงเรียน" และ "ตัวแทนของกลุ่ม(คะแนนสูงสุด)"
