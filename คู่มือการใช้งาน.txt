	โปรแกรมระบบแข่งขันศิลปหัตถกรรมนักเรียนกลุ่มโรงเรียนศรีรัตนะ สพป.ศรีสะเกษ เขต 4 (รุ่น 2569.07.01) เป็นการสร้างสรรค์โปรแกรม Webpage โดยใช้ Google Gemini ช่วย วิเคราะห์ ตรวจสอบ แก้ปัญหาเชิงระบบ และสร้างโค้ดต้นแบบ โดยใช้การบันทึกข้อมูลต่างๆ ลง Google Sheet และรันเว็ปด้วย GitHub การสร้างสรรค์โปรแกรมในครั้งนี้ใช้การทำงานของระบบแบบพื้นฐานที่รองรับผู้ใช้งานได้จำกัน เนื่องจากกลุ่มโรงเรียนศรีรัตนะมี 26 โรงเรียน และจำนวนผู้เข้าแข่งขันไม่ได้มาก Google Sheet จึงรองรับการทำงานต่างๆ ได้หลาย User พร้อมกัน
	รังสรรค์งานโดย นายทนงศักดิ์  โพธิ์พัฒน์ ผอ.รร.บ้านตาแบน อนาคตเราจะพัฒนาโปรแกรมไปสู่ OOP โดยใช้ฐานข้อมูล MySQL และการเข้ารหัสแบบ SSH-128 ให้สามารถนำขึ้น Host/Domain/Website ได้อย่างปลอดภัย

การใช้งานเบื้องต้น
1. เมื่อ Login เข้าสู่ระบบด้วย User ที่กำหนดให้ ท่านสามารถทำการเปลี่ยนแปลง Password ได้ตามความต้องการ
2. เมื่อเข้าสู่หน้า "แดชบอร์ด" สามารถเลือก "ธีมทางการ" ที่กำหนดไว้หรือ "ปรับธีม" ได้อิสระตามความต้องการ กดปุ่ม "บันทึกธีม" ระบบจะบันทึกค่าไว้ที่ "ธีมกำหนดเอง"
   และเมื่่อเข้าสู่ระบบในครั้งถัดไปให้กดเลือก "ธีมกำหนดเอง" แล้วก็กด "บันทึกธีม" 
3. เพื่อให้ใช้โปรแกรมแบบราบรื่น กดฟังก์ชั่น Ctrl+F5 ก่อนเริ่มงาน(จำเป็นอย่างยิ่ง) เพื่อเคลีย์ค่าเก่าที่เคยใช้งานไปในครั้งก่อน และเชื่อมฐานข้อมูล
   (หากไม่กดฟังก์ชั่น Ctrl+F5 โปรแกรมจะไม่นำส่งข้อมูลเข้่าสู่ระบบ)
4. ธีมจะกลับไปอยู่ค่าตั้งต้นให้เลือก "ปรับธีม" ค่าที่เคยตั้งไว้จะกลับมาและกดปุ่ม "บันทึกธีม"
   และเมื่อเข้าสู่ระบบในครั้งต่่อไป ระบบ "อาจจะ" แสดงค่าธีมเริ่มต้น เพียงแต่ท่านต้องไปเลือก "ปรับธีม" ธีมที่เคยใช้จะกลับมา ให้กดปุ่ม "บันทึกธีม" ธีมที่เคยตั้งค่าไว้ก็จะกลับมา
5. สิทธิ์สำหรับ User ทั่วไป(ผู้ใช้งาน)
	5.1 ดูได้ทุกเมนู
	5.2 สามารถลงทะเบียนนักเรียนได้ แต่ไม่สามารถแก้ไข หรือลบข้อมูลได้ ต้องส่งเรื่องให้ Admin ดำเนินการ
	5.3 สามารถสมัคร "กรรมการจตัดสิน" เมื่อกดปุ่ม "สมัครกรรมการ" สมัครจนครบแล้วให้กดปุ่ม "สำรองข้อมูลระบบฯ" โปรแกรมจึงจะนำข้อมูลเข้าระบบ (หากส่งแล้วจะไม่สามารถแก้ไขได้ ต้องส่งเรื่องให้ Admin ดำเนินการเท่านั้น)
	5.4 รายงาน สามาระดูรายงานได้จากปุ่ม "รายงาน" โดยให้รายได้ตาม "รายการแข่งขัน" ,"รายโรงเรียน","ตัวแทนกลุ่ม"
หมายเหตุ  การ "ลงทะเบียนนักเรียน" ไม่ต้องกดปุ่ม "สำรองข้อมูลระบบ(Google Sheet)"  แต่การสมัคร "กรรมการตัดสิน" เมื่อสมัครไปแล้วต้องกดปุ่ม "สำรองข้อมูลระบบ(Google Sheet)" เพื่อให้โปรแกรมนำข้อมูลเข้าสู่ระบบ

การใช้งานบน Smart Phone
1. เมื่่่อใช้งานบน  Smart Phone เมนูแถบข้างซ้ายจะหายไป ต้องกดปุ่ม "เมนูระบบ" เมนูซ้ายจึงจะปรากฏให้เห็น
2. การใช้งานบน Smart Phone ควรวางแนวนอน เพื่อความสบายตาในการมอง
3.  การใช้งานปฏิบัติตามขั้นตอน "การใช้งานเบื้องต้น" ทุกข้อ
4. สำหรับ Smart Phone ไม่สามารถกดฟังก์ชั่น Ctrl+F5 ได้  ผู้ใช้งานจำเป็นต้องกดปุ่ม "รีโหลด" (สัญลักษณ์ ลูกศรย้อมกลับ) แทน
